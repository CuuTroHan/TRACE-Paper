# Quy ước tên file phản biện

Mọi file phản biện được đặt trong thư mục này phải dùng mẫu:

```text
YYYYMMDD-HHMM-github-username-mo-ta-ngan.ext
```

- `YYYYMMDD`: năm, tháng, ngày theo múi giờ Việt Nam (`Asia/Ho_Chi_Minh`).
- `HHMM`: giờ và phút theo định dạng 24 giờ.
- `github-username`: GitHub username của người push file.
- `mo-ta-ngan`: mô tả ngắn bằng chữ thường, ngăn cách bằng dấu gạch nối.
- `ext`: giữ nguyên phần mở rộng của file gốc.

Ví dụ:

```text
20260919-2244-CuuTroHan-springer-submission-audit.md
```

`README.md` này là file hướng dẫn, không áp dụng quy ước tên file phản biện.
